# @daguanren21/vue-doctor-rule-pack-vue

## 0.1.0

### Minor Changes

- Initial public release under the `@daguanren21` scope, providing the Vue Doctor CLI, component-library diagnostics, custom rule APIs, Inspector, MCP server and build-tool integrations.
- Add five opt-in, version-gated Vue AI Skills-informed checks for async computed getters, computed source mutations, conflicting native event modifiers, invalid memo dependencies and unsupported TransitionGroup mode.

### Patch Changes

- Preserve type-only receiver identity, invalidate uncertain direct array-member writes, and exclude deferred generator getter bodies from computed side-effect checks.

- Updated dependencies:
  - @daguanren21/vue-doctor-core@0.1.0
  - @daguanren21/vue-doctor-source@0.1.0
